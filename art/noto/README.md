# Pictures in these folders

The pictures in `art/noto/` come from [Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google.
The project says its image resources are under the Apache License, Version 2.0; the license file copied here
as `LICENSE` is the SIL Open Font License 1.1. Both allow the pictures to be used and shared, including inside
other work, as long as the license notice stays with them.

Files were renamed (for example `emoji_u1f988.svg` became `shark.svg`) and are otherwise unchanged.

`art/noto-line/` holds outline versions of the same pictures, made for printing coloring pages: every shape is
filled white with a dark outline, and very dark parts (like eyes) stay dark. They are changes of the originals and
carry the same license.

Before using any of these pictures in something sold (for example a printable in the Dreamweaver Bay shop),
check the license terms again for that use.
